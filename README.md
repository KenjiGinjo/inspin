# Baikai

用户可以使用公开图片内容创建“手办众筹项目”，通过其他用户进入项目页面进行投票，人气越高，手办化的概率越高，手办化之后用户可以购买手办。

# 最低保证

- 系统最低众筹金额
- 单个手办众筹不能低于最低
- menu 出来的时候报错

- 投票的目标数量
- 众筹的目标数量 后台设置

- point prevent 确认支付 跳转用户登陆的时候 的body bug
- saleCount 的处理

- 现在的逻辑在预售结束的时候 会有15分钟的 时间差 造成 预售结束 但是用户支付的是预售的价格

- model 轮播最多8张
- 订单备注的逻辑，抽奖和正常购买

- 定时生成 genre 关键词
- recommend 、popular 方式先不上
- 优化列表ResVoteShow类似这种的 sql 查询优化性能
- genre 请求 和 constant 优化
